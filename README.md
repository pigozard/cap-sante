# Cap Santé - Prototype Front-End

Prototype statique reproduisant l'interface du LMS Cap Santé (CHU Bordeaux).

## Pages disponibles
- `index.html` : Page d'accueil
- `ateliers.html` : Dashboard des ateliers
- `cours.html` : Page de cours (Trouble Borderline)

## Visualisation locale
Utiliser Live Server dans VS Code ou ouvrir directement `index.html` dans un navigateur.
